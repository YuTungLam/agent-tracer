Blind source evidence review

Judge visible evidence, not the tracer.

For each target argument, identify which visible sources support its content or value. Exact reuse and a defensible transformation can support a selection; mere topical similarity is insufficient. This is evidence attribution, not proof of causality, maliciousness, or authorization.

Items contain no tracer predictions, condition keys, or outcomes. Blinding is partial: the recorded content itself may reveal an injection or task. Do not consult prediction reports, judge outputs, or the private identity key.

Annotation instructions and verdicts
  • Single source: one visible source supports this field's derivation.
  • Multiple sources: distinct visible sources jointly or independently support the derivation. Select every supported source.
  • No visible source: none of the displayed sources supports derivation. Select no sources. This does not establish where the value actually came from.
  • Ambiguous: the visible evidence leaves competing explanations. Explain the ambiguity; optionally select the plausible sources.
  • Unjudgeable: the available record is insufficient or unsuitable. Explain what is missing; do not convert uncertainty into no visible source.

A rationale is required for every item. Source options include user, system, assistant, and tool content visible in the request; they are not a shortlist selected by a model. Message indexes are zero-based. Optional spans use half-open Unicode code-point offsets in the displayed source text. Provider call identifiers in the request prefix have local aliases; content is preserved.
