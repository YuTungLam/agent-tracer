## 4. Environment on a new machine

1. Clone both repositories. Keep the results checkout separate from the code checkout, and confirm its path as `agent-tracer/AGENTS.md` requires.
2. Set up the lab: `packages/agentdojo-lab`, `python scripts/bootstrap.py --python 3.12`, then `dojo-lab doctor`.
   - Bootstrap clones AgentDojo at the commit in `upstream.json` (`089ed468`).
   - Do not run a plain `uv sync` first.
3. MiniLM: place `all-MiniLM-L6-v2` at revision `1110a243` under `packages/agentdojo-lab/.model-cache/all-MiniLM-L6-v2-1110a243`. Runs use `PYTHONUTF8=1 HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1`.
4. Third-party artifacts: re-fetch each one into `<external-auditors>/<key>/src` from its `provenance.json` and check the hash. Then create its venv as described in its `NOTES.md`. The adapters in `packages/auditor-adapters/*/README.md` give the exact test commands per venv.
5. Keys: add `DEEPSEEK_API_KEY` (and `OPENAI_API_KEY` if needed) to `packages/agentdojo-lab/.env` yourself. The guarded runner reads only the key line it needs.
6. Run paid stages only through `packages/auditor-adapters/common/deepseek_route.py run-stage`, from a clean worktree at the frozen commit. Insert `--plan-only` before `--` to dry-check.
   - On Windows the worktree needs the untracked `.venv`, `vendor/` and `.model-cache` from the main checkout (junctions or copies), plus `PYTHONPATH=<worktree>/packages/agentdojo-lab/src`.
